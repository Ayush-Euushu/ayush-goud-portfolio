# Design Direction

## Visual Direction

The portfolio should communicate:

- Programming
- Problem-solving
- Continuous learning
- Practical technical work

Projects should receive strong visual emphasis because they provide evidence
of technical skills.

The interface should feel focused on the content rather than decoration.

## Colour Direction

Follow the visual direction established in the Google Stitch design.

Use a consistent primary accent throughout the interface.

Maintain sufficient contrast between text and backgrounds.

Body text should meet at least a 4.5:1 contrast ratio against its background.

## Typography

Use a strong, clearly visible heading hierarchy.

The name "AYUSH GOUD" should be prominent in the hero.

Body text should be comfortable to read on both desktop and mobile.

Avoid oversized headings that exist only for decoration.

## Layout

### Navigation

Use a top navigation bar containing:

- Home
- About
- Skills
- Projects
- Education
- Experience
- Certifications
- Contact

The navigation should remain usable on smaller screens.

### Hero

The hero should use a two-column layout on desktop:

Left:
Profile image area

Right:
Name, introduction, supporting text and actions

The name should be clearly readable.

On mobile, the hero should stack vertically.

### Projects

Projects are one of the most important sections.

Each project should clearly show:

- Project title
- Description
- Technologies used

Projects should be visually distinguishable from other sections.

### Certifications

Certification entries should clearly show:

- Certification name
- Issuer
- Issue date

Do not create fake verification links.

### Contact

Contact information should be easy to find.

Email and LinkedIn actions should be clearly identifiable and easy to use.

## Interaction

- Navigation links should scroll to the correct sections.
- Buttons should have clear hover/focus states.
- Links should provide appropriate visual feedback.
- Go to Top should return the visitor to the beginning of the page.
- Important actions must remain usable on mobile.

## Responsive Behaviour

### Desktop

Use the available screen width effectively without making content excessively
wide.

The hero should use the image-and-content two-column structure.

### Mobile

- Stack the hero vertically.
- Keep text readable.
- Prevent horizontal overflow.
- Keep navigation usable.
- Keep buttons accessible.
- Prevent project content from becoming cramped.
- Maintain appropriate spacing between sections.

## Avoid

- Large gradient backgrounds
- Glass-effect panels
- Decorative floating shapes
- Excessive animations
- Rows of identical generic cards
- Oversized decorative headings
- Generic AI-generated portfolio patterns
- Unnecessary visual effects
- Invented information
